# QA handover for 8.1.0 (state at 8.1.0-beta.5, 2026-10-06)

Where to start when the accessibility and QA stage for 8.1.0 begins. From
the afternoon of 2026-10-06 the work was built first and tested lightly on
the owner's instruction (decision D71 in `8.1.0-decision-log.md`), so this
file lists what exists, what is known to be wrong, and what nobody has
reviewed. Written by the team manager, the agent that planned and
committed the work. The branch is `release/8.1.0`; beta.5 is commit
`792b901`. No beta was published.

## What is built

From the Quizrundan app's spec tab "Zabi components to add":

- Theming for any brand: palettes declared once, role tokens, accent role,
  `data-theme`, the generator (`zabi-theme`, `createTheme`, `pin`).
- Mobile and touch rework: 44px targets on coarse pointers, pressed states,
  Tabs overflow, Tooltip on touch, Toaster offsets, full-screen Modal, safe
  areas, Select and Dropdown as sheets, bars at 200% text.
- AppShell, AppBar, BottomSheet, StickyActionBar, SegmentedControl,
  BottomTabBar, FloatingActionButton.
- Rating, DateField, TimeField, Calendar, PhotoGrid, PhotoViewer.
- Stepper, Avatar, AvatarGroup, SwipeableListItem, PullToRefresh.

Beyond the tab: the menu responsiveness review (TopNavbar, Dropdown,
NavigationMenu, Tabs), the nested corner radius rule and its guard, the
sidebar's drawer mode, three theme modes, named toast durations,
`ZabiStringsProvider`, a Select that works before hydration and without
scripts, controls that keep a choice made before hydration.

## Ruled out

- LineChart: not built; use a chart library (D32).
- ActionSheet as its own component: it is `Dropdown presentation="sheet"`
  (D48).
- Waiting for a major version: Toggle as a native checkbox; a disabled
  Select not submitting once hydrated.

## Known wrong

- Directly on an `on-brand` or `on-accent` block: an empty or ticked
  checkbox, radio or toggle, a filled Rating star and status message text
  are below contrast. A card inside a block needs `:has()`.
- Select: in forced colours every option has the same border; a long label
  is cut in the native select and the field grows when the custom control
  takes over; the inline `required` message is the browser's, in the
  browser's language; a disabled Select submits once hydrated and not
  before; Safari offers the stand-in option that holds a value with no
  option of its own.
- SwipeableListItem: an action's label does not wrap; with
  `showMoreButton={false}` focus has nowhere to return to after an action.
- PullToRefresh: in controlled mode it says "Updated" even after a failed
  refresh.
- Toaster: the group is named by its first line and contains it, so a
  screen reader entering the group may hear the line twice. Naming the
  group by type was proposed and parked until a screen reader is run.
- Overlay titles: `hyphens: auto` hyphenates a URL in a title.
- `ZabiStringsProvider` does not cover landmark and region `ariaLabel`
  defaults.
- AppBar before hydration or without scripts: when the title takes its own
  row, the actions wrap down with it; they move up once the bar has
  measured itself.
- Avatar's server-rendered initials are upper-cased with the runtime's
  locale unless `locale` is passed (matters for Turkish and similar).
- Docs site: the demo card's "Code" button overlaps a long demo title at
  375px; no "On this page" summary on phones.

## Tests known to be flaky

- `playwright/chaos.spec.ts:271` and `playwright/date-time-field.spec.ts:186`:
  single 60-second timeouts in full runs on a loaded machine; each file
  passes alone.
- Unit tests time out at 5 seconds, in unrelated files, when the machine's
  load average is above about 40.
- `playwright/theme-brands.spec.ts`: two test-side races were fixed in
  beta.3 (it read colours before the brand and the stylesheets were in).
  Under 4x CPU throttling the test "color-scheme goes wherever the dark
  tokens go" (ten page loads) can still exceed 60 seconds.

Last full browser-suite results: beta.3 commit, 1346 passed, 0 failed;
beta.4 commit, 1406 passed, 1 failed (a stale assertion, corrected, not
rerun in full); beta.5, not run.

## What to do first

1. One full browser run on the tip, to know the starting point.
2. Select with a screen reader and in iOS Safari: the native control
   before hydration, the handover, the `combobox` trigger, the sheet. It
   changed the most and forms depend on it.
3. Focus traps in every overlay, now that `getFocusableElements` skips
   `tabindex="-1"` and menus use roving tabindex.
4. The hydration package on a throttled phone with the app's real forms.
5. Avatar, AvatarGroup, SwipeableListItem and PullToRefresh in RTL, forced
   colours, reduced motion and at 200% text.
6. Block colours with the app's own theme (brand `#0026EA`, accent
   `#EB8FFE`).
7. The toast group's name, with a screen reader, to settle the parked
   question.
