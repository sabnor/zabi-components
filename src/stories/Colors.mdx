# Colors

Components never hardcode a color. They read **semantic tokens** such as
`--color-action-primary`, and the semantic tokens point at **ramps** such as
`--zabi-brand-600`. To rebrand, you replace the ramps; the semantic tokens
follow in light and in dark.

Every value on this page is read from the library's stylesheet when this
Storybook is built, so it matches the version you are looking at.

## Ramps

Seven ramps, each with eleven steps from 50 to 950. Base has extra half steps
for surfaces and borders, so it is shown in two rows. All ramps share one lightness curve, so step 600 is
the same lightness in every one of them. Accent is the second brand colour: it
points at Citron step for step until an app sets `--zabi-accent-*`.

## Using tokens

In your own CSS, read the semantic token:

```css
.price-card {
  background-color: var(--color-surface-raised);
  border: 1px solid var(--color-border);
  color: var(--color-body);
}
```

With Tailwind CSS, use the class of the same name:

```html
<div class="bg-surface-raised border border-border text-body">…</div>
```

## Rebranding

Generate one file from your brand colour and import it after the theme. It
replaces the ramps, so one file covers light and dark.

```bash
npx zabi-theme --brand "#C17B00" --neutral "#78716c" --out src/lib/brand.generated.css
```

```css
@import "tailwindcss";
@import "zabi-components/theme-only";
@import "zabi-components/theme-dark-only";
@import "./lib/brand.generated.css";
```

Your colour gives the ramp its hue and saturation; the lightness of each step
is the library's, so the exact hex may not be in the ramp. The theming guide
(`THEMING.md` in the package) lists every token an app may set.

**Check the colors you change.** The colors that ship are contrast checked
before every release: every fill and text pair a component can render passes
WCAG AA in both themes, and the generator holds a new brand to the same pairs. Tokens you set by hand are not checked, so
test the pairs you change, such as a button label against its fill.

## Dark mode

Add the `dark` class or `data-theme="dark"` to the `html` element. Every
semantic token has a dark value, so nothing else changes in your markup.
`data-theme="auto"` follows the system setting.

```html
<html lang="en" data-theme="dark">
```
