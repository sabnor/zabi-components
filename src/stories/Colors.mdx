# Colors

Components never hardcode a color. They read **semantic tokens** such as
`--color-action-primary`, and the semantic tokens point at **ramps** such as
`--zabi-brand-600`. To rebrand, you change what the semantic tokens point at.

Every value on this page is read from the library's stylesheet when this
Storybook is built, so it matches the version you are looking at.

## Ramps

Seven ramps, each with eleven steps from 50 to 950. Base has extra half steps
for surfaces and borders, so it is shown in two rows. All ramps share one lightness curve, so step 600 is
the same lightness in every one of them.

## Using tokens

In your own CSS, read the semantic token:

```css
.price-card {
  background-color: var(--color-surface-raised);
  border: 1px solid var(--color-border);
  color: var(--color-body);
}
```

With Tailwind CSS, use the class of the same name:

```html
<div class="bg-surface-raised border border-border text-body">…</div>
```

## Rebranding

Override the semantic tokens after the theme import. Set the dark values too.

```css
:root {
  --color-action-primary: #0f766e;
  --color-action-primary-hover: #115e59;
  --color-action-primary-text: #ffffff;
  --color-focus-ring: #0d9488;
  --color-link: #0f766e;
}

.dark {
  --color-action-primary: #5eead4;
  --color-action-primary-hover: #99f6e4;
  --color-action-primary-text: #042f2e;
  --color-focus-ring: #2dd4bf;
  --color-link: #5eead4;
}
```

Tokens are CSS custom properties, so they cascade. Set them on any element to
theme only what is inside it.

**Check the colors you change.** The colors that ship are contrast checked
before every release: 84 pairs pass WCAG AA in both themes. Colors you override
are not checked, so test the pairs you change, such as a button label against
its fill.

## Dark mode

Add the `dark` class to the `html` element. Every semantic token has a dark
value, so nothing else changes in your markup.

```html
<html lang="en" class="dark">
```
